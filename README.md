### Base de datos

En la raíz del proyecto se encuentra el archivo `ecommerce_db3.sql`, que contiene la base de datos utilizada para el proyecto ya armada con usuarios, recetas e ingredientes. Para restaurar la base de datos, se puede importar el archivo desde phpMyAdmin: crear una nueva base de datos con el nombre `ecommerce_db3` y luego importar el archivo `ecommerce_db3.sql` en la nueva base de datos.
